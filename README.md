# prima-pr-demo

Un piccolo progetto di prova per fare pratica con il flusso di una Pull Request su GitHub.

## Cosa fa

Contiene alcune funzioni di utilità per lavorare con le stringhe, pensate per essere semplici
da leggere e da estendere.

## Utilizzo

```python
from string_utils import capitalize_words

print(capitalize_words("ciao mondo"))  # "Ciao Mondo"
```

## Sviluppo

Questo progetto e' stato creato apposta per essere migliorato con piccole PR: correzioni di
battitura, test mancanti, piccoli refactor.
